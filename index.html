CommandeDescription

2️⃣ Commandes Essentielles

CommandeDescription
git initInitialiser un dépôt
git clone URLCloner un dépôt
git statusVoir l’état
git add .Ajouter fichiers
git commit -m "message"Créer un commit
git pull --rebaseMettre à jour proprement
git pushEnvoyer les commits

3️⃣ Branches

CommandeDescription
git branchLister branches
git switch -c feature/nomCréer + changer
git merge nomFusionner
git branch -d nomSupprimer

4️⃣ Annulation

CommandeDescription
git restore fichierAnnuler modification
git reset --soft HEAD~1Annuler commit
git revert SHAAnnuler proprement

5️⃣ Avancé

CommandeDescription
git rebase -i HEAD~3Rebase interactif
git stashSauvegarde temporaire
git cherry-pick SHAAppliquer commit
